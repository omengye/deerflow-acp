# 默认模型与高级配置交付说明

日期：2026-09-11。

## 默认模型

- 模型页顶部展示全局默认模型，以及新 ACP 会话的预计模型和来源。客户端仍可为具体会话选择其他模型。
- 模型列表标注“默认”。点击列表仅选择编辑对象；详情顶部“设为默认”才修改全局默认。
- 设置默认模型只修改草稿，通过原有保存、应用流程生效；不会自动发起模型测试或重启服务。
- 删除默认模型必须选择替代模型并确认。取消操作保留原草稿；仍被 Agent、ACP、记忆等引用的模型不能删除；最后一个模型不能删除。
- ACP 提供明确的自动选择选项，固定模型旁显示“不跟随全局默认变化”。其他模型分工用“继承全局默认”替代空白选项。

## 高级配置

侧栏不再提供全局高级设置入口。模型、工具、ACP 会话、记忆和自进化页面分别提供带说明的折叠区。基本设置和权限开关始终显示。

各页独立保存本次使用期间的展开状态；关闭重开应用后默认收起。收起不重置配置和未保存草稿。可校验的错误会使对应高级区保持展开；顶部“查看错误配置”切换至对应页面，并按实际界面布局定位数值字段或高级配置区。

## 验证与升级

Rust 15 项测试通过，包含新增的默认模型切换、显式继承、替代删除、引用保护、独立折叠和错误展开回归。此次修改集中于桌面交互，没有修改 Python ACP 运行逻辑。

实际 Windows 窗口已验证模型选择与设为默认、替代项控制确认按钮、取消删除、记忆高级配置展开、无效输入阻止保存，以及自动滚动并聚焦错误字段。测试使用独立目录中的两个占位模型，未发起模型请求。

已有上一版便携目录时，关闭配置窗口，复制本次 `deerflow-config.exe` 覆盖同名文件即可；也可使用完整 ZIP。交付包保持空白 `user-data`，隔离测试数据不打入交付包。
