# 便携 ACP 改造交付说明

交付日期：2026-09-10。平台：Windows x64。保留 Rust/Iced 桌面技术栈与深色界面。

## 本次交付

1. **接入与状态**：首页接入步骤、复制 Zed 配置、活动与排队计数、每 5 秒刷新状态，以及基于编辑配置的能力预览。
2. **保存与应用**：普通保存保留运行实例；保存并应用先等待已接收任务结束；支持取消等待与确认立即重启。
3. **编辑保护**：重载和关闭时保护草稿；保存期间阻止修改覆盖；字段级数值校验；保留未知 Runtime 字段与 `/goal` 设置。
4. **模型配置**：服务商预设、模型引用同步、手动最小文本测试。仅点击测试时产生一次模型请求。
5. **配置界面**：高级参数折叠、工具和工具组表单、工具与 Skill 搜索、SOUL 与 Prompt Overlay 多行编辑。
6. **数据管理**：备份预览和恢复、会话清理预览和删除、作用域记忆事实查看和删除、自进化历史及版本回滚。
7. **运行行为**：排队与执行分开计时、排队取消、工作区/会话记忆实际隔离、配置写入失败时恢复、启动配置固定。
8. **交付与诊断**：Windows x64 ZIP、存储占用、日志尾部、脱敏诊断报告及本说明。

普通保存不重启服务；权限默认值与清理保留期限保持原设置。配置恢复只处理配置与 Agent 设置，恢复前自动备份。会话删除保留上传和输出产物。旧共享记忆保留在原位置，不自动分配到工作区；新作用域记忆存入 `memory-scopes`。

## 建议验收顺序

请解压到新目录；迁移现有数据前备份原便携目录。

| 操作 | 预期结果 |
|---|---|
| 打开配置工具，填入模型配置，手动测试一次 | 显示成功和耗时，或简明失败原因；测试不保存草稿 |
| 保存并启动服务，复制客户端配置并连接 | 绝对路径正确，客户端能创建会话并完成对话 |
| 修改配置后普通保存 | 当前服务继续运行，界面提示待应用 |
| 任务执行中选择保存并应用 | 显示等待；可取消等待；任务结束后应用新配置 |
| 并发任务超过运行槽位，随后取消等待任务 | 有排队提示，取消及时生效；执行时限从取得槽位后开始 |
| 输入非法数值，或编辑后重新加载/关闭 | 数值错误阻止保存；未保存草稿需确认 |
| 在两个项目测试 workspace 记忆 | 新提取事实按项目隔离；旧共享事实可单独查看 |
| 查看备份、会话、记忆和历史，在测试数据上执行恢复/删除/回滚 | 展示影响并确认；连接中的会话拒绝删除；恢复后提示应用 |

诊断报告保留本地路径，分享前可自行检查。完整操作与兼容说明见包内 `README.md`。
