# 便携 ACP 界面更新

本次重点调整侧栏与公共界面样式。

- 移除侧栏“显示高级设置”复选框，改为整行按钮，配有统一线性图标和“开启 / 关闭”状态标记。
- 侧栏按“配置与能力”“运行与维护”分组，统一 42 像素行高。高级设置固定在底部，菜单区域可滚动。
- 统一中文导航名称，缩短原有英文长标题；当前页面使用底色、图标和箭头共同标识。
- 使用更中性的深灰背景，减轻边框与阴影，统一常用操作按钮的圆角、字号和内边距。
- 顶部标题、状态与操作分为两行，接入引导卡片与内容区域等宽。

Release 编译与格式检查通过。已在独立测试目录打开实际 Windows 窗口，检查首页、模型页、侧栏导航以及高级参数展开/收起。此次只改界面与文案，ACP 运行逻辑沿用上一交付版本。

已有上一版便携目录时，可关闭配置窗口，将新版 `deerflow-config.exe` 复制到原目录覆盖同名文件；用户数据无需迁移。也可下载完整新版 ZIP，解压到新目录使用。
