## 3. 真实 embedding

当前安装没有 embedding URL/model，本轮在临时 Python 3.12.15 / fastembed 0.7.4 / onnxruntime 1.32.0 环境启动 loopback 服务，未改安装配置。Python 3.15 初次安装因缺少 onnxruntime wheel 失败，切换已有 uv 管理的 3.12 后成功；这属于验收环境问题。

使用仓库下载器校验模型全部文件：`BAAI/bge-small-zh-v1.5@46fbe35`，完整 revision `46fbe35fd4374a00fee7de77dfddaeb6dd6a2c59`；ONNX SHA256 为 `1294ea4b6331115a353d81f96b85e8c8d7fdcc284453d5b2fab5b016230aad38`。临时 adapter 来自现有部署 adapter，仅变更模型目录、loopback 临时端口和 readiness 元数据，摘要与依赖清单保存在验收记录中。

最终加强测试：20 个事实均有 512 维有限非零向量，2 次 index embedding、100 次 query embedding、0 次 embedding 错误；100 条中文查询 **Recall@5=0.950，p95=115 ms**，workspace 隔离通过。统计发生在额外的隔离查询之前。首轮未加强测试同为 0.95、p95=125 ms，仅作历史记录；最终结果不能由词法回退冒充 embedding 成功。

这是 20 条语料的混合检索验收，不是纯向量检索的独立召回指标，也不是 10000 向量的性能测试。临时服务已停止并确认监听端口关闭。
