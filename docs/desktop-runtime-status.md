# 桌面运行状态面板

右侧的 **DeerFlow 运行状态** 面板默认展示当前会话的执行情况。对话上方的 **运行状态** 按钮可以打开它。

- **主 Agent** 展示连接、思考、生成回复、执行、等待审批或回复等状态，以及当前或最近一次工具活动。
- **Todo 进度** 展示当前轮次的计划、待执行 / 进行中 / 已完成状态，以及已完成条目占比。计划通过 ACP 实时更新；未上报计划时显示空状态。对话结束或中断不会自动完成 Todo。
- **子 Agent** 展示角色、任务描述、前台或后台模式、模型、等待原因，以及宿主已记录的模型调用、工具调用和 token 用量。运行和等待的任务排在前面；已完成记录只展示当前轮次最近一棵根任务中的子 Agent。较早轮次仍未结束的子 Agent 继续显示。

Agent 状态在连接期间、面板可见时每 5 秒刷新，收到运行时通知时也会刷新。列表会自动读取后续页，受现有缓存数量和大小限制；分页未完整加载、按根任务筛选或断开连接时会标明状态。没有上报调用用量时显示“调用进度尚未上报”。调用次数用于了解执行活动，不作为任务完成百分比。

**任务详情与管理** 保留原任务树、完整任务结果、取消、恢复、审批、工具效果核对和产物入口。点击子 Agent 可以查看该任务详情，再通过 **返回运行状态** 回到概览。

Todo 按当前对话轮次展示。重新打开历史会话会恢复该轮已保存的计划，新一轮任务不会沿用上一轮的 Todo。根任务 token 用量包含后代，与子 Agent 的自身用量不能累加。
